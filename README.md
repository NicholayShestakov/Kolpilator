# Компилятор MiniML
Учебный компилятор в рамках ЛШ СПбГУ. Компилирует MiniML (подмножество Ocaml) в ассемблер risc-v x64.
# Использование
Должен быть установлен dune. Рекомендуется версия 3.22. На остальных работоспособность не гарантирована.  
В корне проекта выполните:
```
$ dune exec src/main.exe -- <path to file for compile> <name of compiled file>
```
На выходе получится файл с risc-v ассемблером.
# В язык включено
- Целые неотрицательные числа.
- Переменные.
- `+, -, *, <`.
- Скобки для приоритизации операций.
- False - 0, True - всё остальное.
- Присвоение переменным значений с помощью `let`.
- Глобальные функции одного аргумента.
- Ветвление путём `if then else`.
- Точка входа - `let main = <something>`. 
- Возвращается результат тела main в качестве кода возврата.
